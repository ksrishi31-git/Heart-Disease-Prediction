HEARTGARD AI

AI-powered web application for predicting heart disease using Machine Learning.

Live Demo

https://heartguard-ai-ecnb.onrender.com/


Features

* Heart disease prediction
* Logistic Regression Machine Learning model
* Interactive web interface
* React frontend
* FastAPI backend
* Heart disease dataset
* Deployed web application

Tech Stack:

Frontend

* React
* JavaScript

Backend

* Python
* FastAPI

Machine Learning

* Scikit-learn
* Logistic Regression
* Pandas
* NumPy

How It Works

1. User enters the required health information.
2. The frontend sends the data to the backend.
3. FastAPI processes the input.
4. The Machine Learning model predicts the result.
5. The prediction is displayed on the website.
